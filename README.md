A [make.fun](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) entry: one haiku about debugging, in the 5-7-5 syllable shape.

`main.py` writes the haiku to `/output/entry.txt` (stdlib only, no dependencies):

```text
One red dot at three
the log insists all is well
the typo was mine
```

Run it with:

```sh
python3 main.py
```
